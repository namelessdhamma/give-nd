## Architectural invariant

PLM remains an embedded True Research mode, not a standalone skill, controller, state owner, or sixth research skill.

## Function

Convert **already-supported** semantic, constitutive, relational, empirical, or direct understanding into the smallest sufficient hinge relevant to the caller's bounded purpose.

Generic selection order:

```text
goal relevance
→ discriminative value / observability
→ practical or decision accessibility
→ adequate support
→ simplicity
```

The exact ordering may be profile-adjusted where domain purpose requires it, but evidence support and status preservation are never optional.

## Non-goals

PLM does not:
- reopen semantic/source analysis;
- perform new constitutive analysis;
- create a new causal/system relation;
- upgrade evidence;
- choose a Research Unit;
- change global priority;
- write durable state.

If a useful hinge depends on unsupported upstream analysis, return EVIDENCE_REQUIRED / a material prerequisite to the host True Research `skills://plugins/nd-true-research/nd-launch-true-research` rather than inventing it.

## Input

Consume already-supported material with:
- exact upstream refs;
- purpose;
- inherited status ceiling;
- framework/scale where material;
- uncertainty/limits;
- reopening conditions where material.

## Output

Return the smallest supported reduction:

```text
hinge
why it matters to the bounded purpose
observable discriminator/check
material dependency or caveat
status ceiling
support refs
```

Rendering is profile-specific. The universal mode does not force See→Do→Check.

## Safeguards

1. Reduction cannot strengthen evidence.
2. Simplicity cannot erase a material dependency, countercondition, uncertainty, or scope limit.
3. A selected hinge is not claimed to be the deepest, sole, universal, or causally sufficient factor unless evidence establishes that.
4. Do not introduce new constitution or relation claims during synthesis.
5. Preserve enough provenance to reopen upstream evidence.
6. Do not choose implementation/action outside the caller's authority ceiling.
7. Routine outputs are ephemeral. If durable consideration is justified, PLM returns eligibility to the host True Research `skills://plugins/nd-true-research/nd-launch-true-research`; authorized persistence/currentness is requested only through True Memory `skills://plugins/nd-true-memory/nd-launch-true-memory` as a bounded PEER_SERVICE. System is retired / historical-only / nonroutable.
